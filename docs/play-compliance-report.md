### User Data

#### App does not create accounts; accounts are owned and deleted on bookmeter.com
- **Policy**: **Account Deletion Requirement**
- **Severity**: 🔵 Suggestion
- **Files**: [LoginScreen.kt](file://src/main/kotlin/com/futabooo/android/booklife/ui/login/LoginScreen.kt), [SettingsScreen.kt](file://src/main/kotlin/com/futabooo/android/booklife/ui/settings/SettingsScreen.kt)
- **Evidence**: Login only authenticates an existing bookmeter.com account (the 'Sign Up' button opens the bookmeter.com sign-up page in the browser via openUrl). Sign-out in SettingsScreen clears the local session cookie. No account is created on a developer-controlled backend.

**Critic Verification**: Automatically verified (bypassed critic review). (Confidence: High)
- **Recommendation**: In the Play Console account-deletion declaration state that accounts are created and deleted on bookmeter.com (third-party service) and link a web page (e.g. the privacy policy / README section) explaining that. Consider adding a direct link to bookmeter's account settings.
- **References**:
  - https://support.google.com/googleplay/android-developer/answer/10144311#account_deletion
  - https://support.google.com/googleplay/android-developer/answer/13327111

### Play Console Requirements

#### App is gated behind a bookmeter.com login screen; Play reviewers need demo credentials
- **Policy**: **Login credentials**
- **Severity**: 🟡 Important
- **Files**: [SessionRepository.kt](file://src/main/kotlin/com/futabooo/android/booklife/data/repository/SessionRepository.kt), [LoginScreen.kt](file://src/main/kotlin/com/futabooo/android/booklife/ui/login/LoginScreen.kt), [LoginViewModel.kt](file://src/main/kotlin/com/futabooo/android/booklife/ui/login/LoginViewModel.kt)
- **Evidence**: LoginScreen is the first screen after splash (Splash -> Login -> Main); every feature (home, shelves, search, registration) needs a bookmeter.com session cookie obtained in SessionRepository.login via BookmeterApi.

**Critic Verification**: Firebase Crashlytics/Analytics diagnostics are collected by SDK; confirmed from dependencies. (Confidence: Medium)
- **Recommendation**: In Play Console > App content > App access, provide a working, non-expiring bookmeter.com test account (email + password) and instructions.
- **References**:
  - https://support.google.com/googleplay/android-developer/answer/15748846
